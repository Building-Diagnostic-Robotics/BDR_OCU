# Robot Data Uploader (Client-Side)

This tool uploads robot run data from a client-managed laptop to AWS S3
using presigned URLs generated by your backend.

-   No AWS credentials stored on the laptop
-   Files are uploaded directly to S3
-   A manifest.json is generated automatically
-   /complete marks the run finished

------------------------------------------------------------------------

# Overview

For a given run folder, the uploader:

1.  Recursively scans all files
2.  For each file:
    -   Calls POST /presign
    -   Uploads file to S3 using the presigned URL
3.  Generates manifest.json (file list + metadata)
4.  Uploads manifest.json last
5.  Calls POST /complete

All files are uploaded under:

`<client_id>`{=html}/`<robot_id>`{=html}/`<run_id>`{=html}/`<relative_path>`{=html}

------------------------------------------------------------------------

# Requirements

-   Python 3.10+
-   Internet connection
-   Valid CLIENT_ID and DEVICE_TOKEN

------------------------------------------------------------------------

# Setup (Recommended: Virtual Environment)

python3 -m venv venv source venv/bin/activate pip install --upgrade pip
pip install requests tqdm

------------------------------------------------------------------------

# Configuration (Important)

Open uploader.py and update ONLY the following section:

API_BASE = "https://zx8j0tqep2.execute-api.us-east-1.amazonaws.com"
CLIENT_ID = "clientA" DEVICE_TOKEN = "TOKEN123" MAX_FILE_BYTES =
3_000_000_000

## Fields You SHOULD Change

API_BASE -- Your API Gateway invoke URL (include stage if needed).
CLIENT_ID -- Your assigned client identifier. DEVICE_TOKEN -- Per-client
authentication token. MAX_FILE_BYTES -- Must match backend limits.

## Fields You SHOULD NOT Change

-   /presign endpoint path
-   /complete endpoint path
-   S3 PUT logic
-   Content-Length header handling
-   Encryption header (x-amz-server-side-encryption)
-   Manifest structure

------------------------------------------------------------------------

# Running the Uploader

python uploader.py `<data_root>`{=html} `<robot_id>`{=html}
`<run_id>`{=html}

Example:

python uploader.py run1 roofus-01 test-run-002

Arguments: - data_root → Folder containing files to upload - robot_id →
Robot identifier - run_id → Unique run identifier

------------------------------------------------------------------------

# What Gets Uploaded

Example S3 structure:

clientA/ roofus-01/ test-run-002/ lidar/scan1.txt thermal/frame1.txt
logs/startup.log manifest.json \_UPLOAD_COMPLETE.json

------------------------------------------------------------------------

# Troubleshooting

NameResolutionError → Fix API_BASE 501 Not Implemented → Do not use
chunked upload AccessDenied → Check bucket policy or expired URL 403
from /presign → Token mismatch

------------------------------------------------------------------------

# Security Notes

-   Never store AWS access keys on client laptops.
-   Rotate DEVICE_TOKEN periodically.
-   Do not share presigned URLs publicly.
